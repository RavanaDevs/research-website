Research Overview

Predictive Maintenance for Sri Lanka's Vehicle Fleets

Commercial vehicle fleets in Sri Lanka continue to rely on reactive and schedule-based maintenance practices, resulting in unexpected breakdowns, revenue loss, and inefficient use of resources.

The OBD-II standard, mandatory on vehicles manufactured after 2001, provides a rich continuous stream of engine telemetry that remains largely unexploited by fleet operators in developing economies.

This research presents a complete end-to-end system: from a custom low-cost IoT device, through a cloud-based data pipeline, to a two-stage hybrid machine learning engine capable of real-time anomaly detection and specific fault code classification.

IoT Data Acquisition

ESP32 + ELM327 device polling 14 OBD-II PIDs at 1 Hz, transmitting over MQTT to a cloud backend.

Physics-Based + GAN Dataset

60,000 balanced samples generated via thermodynamic simulation (Cantera) augmented by CTGAN — solving real-world data scarcity.

Two-Stage ML Pipeline

LSTM-Autoencoder for unsupervised anomaly detection followed by a Random Forest classifier for specific DTC identification.

Real-Time Fleet Dashboard

React-based fleet manager dashboard with WebSocket alerts, telemetry gauges, and actionable maintenance recommendations.

How It Works

Three-Stage System Pipeline

From raw vehicle telemetry to actionable maintenance alerts — entirely automated in real time.

1

Data Acquisition & Ingestion

The ESP32 IoT device continuously polls 14 OBD-II PIDs at 1 Hz via an ELM327 adapter. Readings are serialised as JSON and published over MQTT to a Mosquitto broker, where they are ingested into a TimescaleDB hypertable.

IoT · MQTT · ESP32
2

Stage 1 — Anomaly Detection

An LSTM-Autoencoder trained exclusively on normal driving data computes reconstruction error over a 60-second sliding window. Windows exceeding the μ+3σ threshold (0.5493) are flagged as anomalous and forwarded to Stage 2.

LSTM-Autoencoder · AUC-ROC 0.8011
3

Stage 2 — Fault Classification

A Random Forest classifier processes a 33-dimensional engineered feature vector (14 raw + 14 delta + 5 ratio features) to identify the precise Diagnostic Trouble Code from 5 fault classes, with 89.32% overall accuracy.

Random Forest · 89.32% Accuracy

Model Performance

Strong Results on Synthetic Training Data

The two-stage pipeline was trained entirely on physics-simulated and CTGAN-augmented data, yet achieves near-real-world performance — validating the data generation approach for data-scarce environments.

Four of five fault classes achieve F1-scores above 0.93. The LSTM-Autoencoder delivers near-perfect precision (0.9836), minimising costly false alerts for fleet operators.
